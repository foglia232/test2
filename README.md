# 穿越宫斗剧，你会是哪位大女主？

## 直接使用

`dist/index.html` 是完整的网页，双击就能在浏览器里打开。

部署到 Netlify：登录 Netlify → Add new site → Deploy manually → 把 `dist` 文件夹整个拖进去。

## 隐藏预览页

在网址后面加 `#all`（例如 `index.html#all`），可以直接查看 16 位人物的结果报告，方便检查文案。这个页面不会出现在正常流程里，也不会写进测试记录。

## 文件说明

| 文件 | 内容 |
|---|---|
| `src/data.js` | 全部文案：16 位人物、八个维度、30 道题、报告用语 |
| `src/engine.js` | 计分规则 |
| `src/sim.js` | 概率模拟，校准每个人物的出现率 |
| `src/calib.js` | 模拟结果（自动生成，不要手改） |
| `src/app.js` | 页面流程、报告、蛛网图、分享卡、测试记录 |
| `src/style.css` | 样式 |
| `fonts/` | 书法标题字体（马善政楷书，SIL Open Font License，可商用） |

## 修改以后怎么重新生成

需要电脑上装有 Node.js 和 Python（`pip install fonttools brotli`）。

- 只改了文案（不动 `w` 权重）：运行 `node build.js`
- 改了题目、选项或权重：先运行 `node src/sim.js` 重新校准概率，再运行 `node build.js`

`sim.js` 会打印每个人物的出现率，正常情况下都应该在 5%–8% 之间，并且"自检"一栏全部是 OK。

## 计分方式

1. 每个选项给 1–3 个维度加分，25 题加总得到八维原始分。
2. 和"随机作答"的平均水平比较，换算成标准分（蛛网图上的 0–100 就是这个百分位）。
3. 每位人物有一个八维画像（两项突出、一项最弱），与用户的标准分比距离，最近的就是结果。
4. 用 3.6 万份模拟作答（随机型 + 按性格倾向作答型）校准，保证 16 位人物出现率大致均衡。
